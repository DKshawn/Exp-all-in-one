# Exp-all-in-one

[日本語](README.md) · [中文](README.zh-CN.md) · [English](README.en.md)

Double Auction、EMH、Judgement under Uncertainty、確率的進化ゲームを一つの入口から実施する授業用実験プラットフォームです。初期表示は日本語です。

学生の待機画面は共通のカードデザインを使い、実験ごとの情報を表示します。実験選択ではカード全体をクリックします。実施中は教員が赤い「実験を終了」を押し、確認して終了できます。

[教員入口](https://exp-all-in-one.vercel.app/teacher) · [学生入口](https://exp-all-in-one.vercel.app)（教員入口は学生画面とは別のURLです）

EMH の注文板は価格と数量を表示し、自分の指値は「一覧」と「棒グラフ」の両方で分かります。教員は取引記録と CSV で買い手・売り手の番号を確認できます。買い・売りそれぞれで指値注文と成行注文を横に並べます。実験2では本人の状態別配当と公開確率の積を表示します。ラウンド末は実現した状態のカードを強調して知らせます。未成立の指値は期末まで価格順、同額では受付順に並び、本人が変更・取消できます。入力中の買値・売値も同じ期の取引間で保持します。

確率的進化ゲームでは手動・タイマーで入室を締め切り、教員が一時停止・進行・早期終了を操作できます。学生は回答と個人記録を同じ画面で確認できます。デモの初期値は自分1人と模擬参加者5人です。デモルームを作成すると操作パネルで教員・学生の画面を切り替えられます。どちらの画面でも一時停止して結果を確認でき、再開や30秒の早送りもできます。表示言語は各自がヘッダーで選びます。

教員がルームを作って共有し、学生はコードで入室し、教員の指示に応じてニックネームまたは学生証番号を入力します。実施する実験とルールは教員が案内し、終了後に教員が結果をダウンロードします。

Double Auction の教員画面では、実験開始後に「学生の割り当て」を折りたたんで表示し、必要なときに開けます。デモでも同様です。

教員用キーは教員入口で一度だけ入力します。同じブラウザーでは8時間、再読込・実験切替・ルーム作成・管理で再入力せずに使えます。「ログアウト」、有効期限切れ、キー変更後は再認証します。ルームごとの教員パスワードは別に保持します。

EMHの価格・配当・売買収支・損益は円で表示します。

EMHは開始操作後、取引画面の「あなたの条件」の真上に5秒のカウントダウンを表示し、条件を矢印と枠で強調して、学生が条件を確認してから取引を開始します。時計の横のラウンド表示は確率的進化ゲームと共通です。終了した回は明るい緑、現在の回はデモではオレンジ、正式実験では紫で示します。

EMHの Demo Model では実験1と実験2を選べます。実験2は既定12人の市場と練習用の配当・状態を使い、学生は状態別条件を確認できます。どちらの実験でも、学生画面に左右に分けた買売操作・市場価格・自分の記録を同時に表示します。進行中の教員画面では条件を開閉できます。 画面サイズ別のプレビューは `/emh/demo/preview` で開けます。

独立した [EMH 実験2 AI 学生プログラム](ai-emh/README.md) は、学生 API を通じて人数を指定して参加し、ローカルモデルまたは OpenAI で判断します。ルームリンクからコードを読み取り、ローカルモデルの URL に `/v1` を補い、必要な API キーや Token は画面に表示せず入力できます。モデルが応答しない場合もルール型 robot は使いません。 AI の操作記録にはモデル要求の所要時間と見送り理由も記録されます。 モデルの出力上限は既定で 1 要求あたり 2048 tokens です。 AI が待機を選ぶと、学生画面の市場情報を監視し、注文や取引などの変化を検知してから再判断します。

LM Studio には長い思考を無効にする任意の高速モードがあり、完全な JSON コードブロックも読み取れます。

EMHでは全員が提示でき、相手の価格を受ける操作と跨ぐ提示は1単位が即時成立します。学生は匿名の取引記録と注文板で自分の未成立の指値を確認でき、実験1の損益にはB期末まで「暫定」と表示します。 保有証券・売買収支・ラウンド損益は学生画面の「あなたの条件」に3枚のカードとして横並びで表示します。

実験2では初期証券数、連続不成立回数、内部情報の開始ラウンド・各タイプ人数、状態確率・配当、市場数・目標人数・タイプ比率を設定できます。開始時に各ラウンドの状態を設定確率に従って抽選・保存し、同じルームの市場で共有します。Clueには抽選結果を表示します。市場数は自動または指定で、実人数を各市場3〜999人に分けます。既定は12人、初期2単位、連続2回不成立、第3ラウンドから各タイプ最大2人です。

EMHデモの操作パネルでは、教員・学生画面の切替、一時停止、30秒進める、次の期へ進む、やり直す、設定の見直しができます。時間を進めると仮想参加者の取引と期限も順に処理されます。カウントダウン中や一時停止中は早送りできません。「やり直す」は設定を保って割り当てと進行をリセットします。画面サイズ別プレビューでは操作パネルを枠外に表示します。

[画面で見る使い方・再入室・ルーム管理](docs/guide/ja/classroom.md) · [Demo Model の使い方](docs/guide/ja/demo.md)

教員は一度ログインすると **Demo Model** を利用できます。デモや画面サイズ別プレビューのURLを直接開く場合も教員ログインが必要です。デモ一覧と各デモ画面は黄色系で表示し、ヘッダーの「市場実験室」の横に「DEMOモード」を表示します。「市場実験室」と「戻る」でデモの実験選択へ戻れます。青紫色の「DEMOモードを終了」で対応する教員の実験設定へ戻れます。デモ一覧から終了した場合は教員の実験選択へ戻ります。

Judgement の教員画面と Demo は課題カード・選択一覧・操作欄を共用します。日中英を切り替えられ、実施中の条件は固定されます。
